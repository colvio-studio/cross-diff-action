> **対象読者**: システム管理者、Salesforce アーキテクト、CoE チーム

## 1. 概要

本ガイドでは、Enterprise / Unlimited Edition をご利用の組織において、CrossDiffAction を部門別・業務フロー別に最適化するための高度な設定、ガバナンス制御、全社プリセット共有、およびエクスポート監査ログの活用方法について解説します。

---

## 2. 部門別専用比較ビューの構築 (FlexiPage カスタマイズ)

Lightning アプリケーションビルダーの `allowedObjects` プロパティを活用することで、営業部門用、サポート部門用、調達部門用など、各ロールに特化した比較画面を作成できます。

### 設定例:
- **営業専用ページ**: `allowedObjects = "Opportunity,Account,Quote"`
- **カスタマーサポート専用ページ**: `allowedObjects = "Case,Asset,Contact,WorkOrder"`
- **契約・法務専用ページ**: `allowedObjects = "Contract,Order,Quote"`
- **カスタムオブジェクト監査**: `allowedObjects = "Invoice__c,Shipment__c,Payment_Log__c"`

### 配備手順:
1. Salesforce の **設定** ➔ **ユーザーインターフェース** ➔ **Lightning アプリケーションビルダー** を開きます。
2. 対象の Lightning ページ（アプリケーションページまたはレコードページ）を編集します。
3. **`CrossDiffView`** コンポーネントを選択します。
4. 右側のプロパティパネルで、**Allowed Objects** にカンマ区切りで対象オブジェクトの API 参照名を入力します。
5. ページを保存し、プロファイルやアプリケーションに割り当てて有効化します。

## 3. ガバナンス & FLS (項目レベルセキュリティ) 継承

CrossDiff は Salesforce 標準の共有モデル（OWD, ロール階層, 共有ルール）および FLS を 100% 継承します。
- **共有モデルの完全遵守**: 組織の共有設定、ロール階層、手動共有、条件に基づく共有ルールを 100% 尊重します。
- **Apex USER_MODE の徹底**: 全ての SOQL 読み取り処理は `WITH USER_MODE` で実行されます。ユーザーに参照権限のない項目やレコードは一切取得されません。
- **動的 FLS ストリッピング**: マトリクスの一括 DML 更新は `Security.stripInaccessible(AccessType.UPDATABLE)` を通過します。更新権限のない項目はフロントエンドで保護され、データベース層でも確実にブロックされます。
- **二重管理ゼロ**: アプリ独自のセキュリティ定義や二重メンテナンスの手間は一切発生しません。

## 4. 全社プリセット配布 ＆ 管理者ロック機能

大規模組織では、四半期レビューや監査用の統一比較テンプレート（指定項目セットやソート条件）を管理者が一括配布し、一般ユーザーによる誤変更を防止する運用が求められます。

### 4.1. プリセットデータモデル (`CrossDiff_Preset__c`)
- **全社共有フラグ (`Is_Global__c`)**: 有効化すると、組織内の全ユーザーのプリセット選択肢に表示されます。
- **管理者ロックフラグ (`Is_Locked__c`)**: 有効化すると、一般ユーザーはプリセットの読み出し・適用のみが可能となり、上書き保存や削除が完全に制限されます。

### 4.2. 権限セット別の操作可否
| 操作 | 一般ユーザー (`CrossDiff_User`) | システム管理者 (`CrossDiff_Admin`) |
| :--- | :---: | :---: |
| **個人プリセットの作成・更新** | ✅ 可能 | ✅ 可能 |
| **全社プリセット (`Is_Global__c`) の作成** | ❌ 制限 | ✅ 可能 |
| **プリセットのロック / 解除 (`Is_Locked__c`)** | ❌ 制限 | ✅ 可能 |
| **全社プリセットの削除** | ❌ 制限 | ✅ 可能 |

## 5. エクスポート監査ログ & コンプライアンス管理

CRM データをスプレッドシートとしてダウンロードする際のデータ漏洩防止（DLP）およびセキュリティ監査に対応するため、CrossDiffAction は全エクスポートイベントの自動ログ記録機能を標準搭載しています。

### 5.1. 監査ログオブジェクト (`CrossDiff_Export_Log__c`)
ユーザーが Excel（`.xlsx`, `.xls`）または CSV（`.csv`）を出力した瞬間に、以下の監査レコードが変更不可のログとして自動作成されます:
- **実行ユーザー (`User__c`)**: エクスポートを実行した Salesforce ユーザーへの参照。
- **実行日時 (`Export_Time__c`)**: ファイル生成時の正確な UTC タイムスタンプ。
- **対象オブジェクト (`Object_Api_Name__c`)**: 比較対象オブジェクトの API 名（例: `Opportunity`）。
- **出力レコード件数 (`Record_Count__c`)**: スプレッドシートに含まれるレコード総数。
- **出力項目数 (`Field_Count__c`)**: 出力された縦軸項目の総数。
- **出力形式 (`Export_Format__c`)**: `XLSX`, `XLS`, `CSV`。
- **実行コンテキスト**: ブラウザメモリ内 100% 生成の完全保証（外部サーバーへの通信ゼロ）。

### 5.2. 同梱カスタムレポートタイプ (`CrossDiff_Export_Logs`)
パッケージインストール直後から、監査ダッシュボードを標準レポート機能で容易に構築できます:
1. Salesforce の **レポート** タブを開きます。
2. **新規レポート** をクリックし、**`CrossDiff Export Logs`** を検索・選択します。
3. `Object_Api_Name__c` や `User__c` でグループ化し、データ出力頻度やエクスポート推移を可視化できます。

## 6. アトミック一括保存 & 部分成功ドラフト保護

マトリクスインライン編集におけるエンタープライズレベルの耐障害性機能です:

- **画面上部ドック未保存バー**: 未保存の変更セル総数・対象レコード数を常時明示し、ワンクリックで保存またはキャンセル可能。
- **部分成功の自動分離（Partial-Success Isolation）**: 4件中3件の保存に成功し、1件に入力規則違反等のエラー（`FIELD_CUSTOM_VALIDATION_EXCEPTION`）が発生した場合、成功した3件のみをコミットし、失敗レコードのみ未保存ドラフトとして画面上に保持します。
- **セル単位エラー赤枠ハイライト**: エラーとなったセルを赤枠（`#EA001E`）で強調し、プラットフォームのエラーメッセージをツールチップポップオーバーで正確に表示します。
- **基準値の一括反映 (Copy from Base)**: 基準レコードの値をワンクリックで他レコードに一括コピーし、目視確認後に安全に保存できます。
