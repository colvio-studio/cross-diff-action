CrossDiffAction — 行ヘッダ・列ヘッダ表現 3案 (案1-Aベース)

外枠と内側マトリクスボードの隙間を活用し、「行ヘッダ」と「列ヘッダ」の存在を直感的にわかりやすく表現した 3 つのデザインアプローチです。

案 1-A-1 • 抽象ピルチップ型
Header Pill Chips
外枠と内枠の隙間に、各列（3つ）と各行（3つ）に対応する独立した丸角ピルチップを配置。文字を使わず抽象UIラベルとしてクリーンに表現。

32px
  • 表現: 列上部と行左部に独立したピル（バー）。
  • 利点: 言語非依存で極小サイズでも潰れず、UIリズム感が美しい。
  • 連動: 左下行チップと右上列チップがシアン発光し、転置フローと呼応。
案 1-A-2 • 軸ルーラーレール型
Axis Ruler Rails
上辺（X軸：列）と左辺（Y軸：行）に連続した一体型ルーラーレールを敷き、角に原点ドット、各位置に目盛スロットを組み込んだ精密デザイン。

32px
  • 表現: X軸・Y軸の繋がったレール＋目盛スライダー。
  • 利点: 「縦軸（行）と横軸（列）を変換する精密ツール」というハイテク感。
  • 連動: Y軸下端の目盛からX軸右端の目盛へアークが架橋。
案 1-A-3 • 英数インデックス型
Spreadsheet "A B C / 1 2 3"
スプレッドシートでおなじみの列「A B C」と行「1 2 3」のヘッダープレートを隙間に配置。「表・マトリクス」であることが一瞬で誰にでも伝わる決定版。

  • 表現: 列上部に「A B C」、行左部に「1 2 3」を配置。
  • 利点: 誰もが知るスプレッドシート記法により、0.1秒で表と理解可能。
  • 連動: 「行3」から「列C」への転置（Row 3 → Col C）が論理的にも明確。
